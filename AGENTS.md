# Project rules (Photos by MP)

- Only Marcantonio's own photos, and only ones he has chosen. Never add stock or AI-generated images.
- No photos that show other people's faces, home addresses or location details without their consent. Strip GPS and other EXIF location data before committing.
- Keep images web-sized (resize and compress) so the page stays fast. Never commit full-resolution originals.
- Describe the project honestly: Marcantonio decides what it does and reviews and tests each change; AI coding tools help write the code.
- Plain HTML/CSS/JS with no build step, so Cloudflare can serve `site/` directly. Check pages at 390px and 1280px.
- Plain, direct writing with no em dashes.
